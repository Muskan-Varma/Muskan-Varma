## 🚀 Featured Projects

### 🤖 [AI-Powered Financial Analysis Platform](https://github.com/Muskan-Varma/AI-Powered-Financial-Analysis-Platform)
> *Python · PySpark · Scikit-learn · SQLite · Streamlit · Ollama (LLaMA 3.2)*

An end-to-end ML + data engineering platform for real-time stock market analysis.

- 📈 Processed **8,000+ rows** of live stock data (AAPL, MSFT, GOOGL, AMZN, TSLA) with PySpark 3.5
- 🔧 Engineered financial features: RSI, MA7/30/90, Sharpe Ratio, Volatility, 150 lag features
- 🧠 **GBT Regressor** for 7-day price forecasting + **Random Forest Classifier** with **92.85% accuracy** for investment grade classification (High / Medium / Low)
- 💬 AI chatbot powered by LLaMA 3.2 with real-time stock context injection via Ollama
- 📊 5-tab interactive Streamlit dashboard with full pipeline control
- ✅ **17/17 Pytest tests passing**
